# HTML Practice Projects

A structured collection of HTML practice exercises created while learning and strengthening the fundamentals of web development.

This repository contains hands-on practice covering HTML page structure, text elements, links, lists, tables, forms, media, selectors, combinators, typography, and basic webpage creation.

The purpose of this repository is to maintain a record of my learning progress and build a strong foundation before moving into advanced CSS, JavaScript, frontend development, and full-stack web development.
